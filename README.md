# MyRoute - app

Aplicación móvil para planificar y personalizar rutas turísticas en Guadalajara de Buga.

## 🚀 Objetivo
Mejorar la experiencia turística permitiendo a los visitantes crear rutas personalizadas, visualizar mapas y gestionar sus recorridos.

---

## 📂 Tecnologías
- **Frontend:** Flutter
- **Backend:** Node.js
- **Base de Datos:** Firebase Firestore
- **Metodología:** Scrum

---

## 🔄 Reglas de Colaboración
Este proyecto utiliza el flujo **GitHub Flow**:

1. **main** es la rama protegida (no se permite push directo).
2. Para nuevas funcionalidades:
   - Crear una rama desde `main` con el formato:  
     `feature/nombre-funcionalidad`
3. Para correcciones:
   - Crear rama:  
     `hotfix/nombre-correccion`
4. Subir cambios y crear **Pull Request** hacia `main`.
5. Al menos **1 revisión aprobada** antes de hacer merge.
6. Todos los PR deben pasar pruebas automáticas (cuando estén configuradas).

---

## ✅ Configuración del Repositorio
- Protección en la rama `main`.
- Revisión obligatoria para merge.
- Uso de Issues para seguimiento de tareas.
